Sobre Mim

Como o interesse pelo funcionamento interno dos sistemas guia a forma como eu construo software.

Do núcleo dos dados à API

Sou estudante de Desenvolvimento de Software Multiplataforma com foco em backend, bancos de dados e confiabilidade de sistemas.

Gosto de trabalhar perto do núcleo das aplicações: desenhando modelos de dados, escrevendo SQL eficiente e construindo serviços que movem dados com segurança entre sistemas. Um sistema bom começa por um modelo de dados bem pensado.

Boa parte do meu aprendizado vem de entender como sistemas reais funcionam por baixo dos panos, principalmente em ambientes Linux, lidando com automação, integrações e troubleshooting no dia a dia.
